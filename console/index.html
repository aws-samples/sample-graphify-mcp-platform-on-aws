    소스 등록

    소스의 목적과 내용을 적으세요. 공개 소스의 설명도 공개됩니다. 그룹 안에서의 역할과 설명은 별도로 설정합니다.

    퍼블릭 레포는 플랫폼 전체에서 공유(풀링)됩니다. 이미 등록된 레포라면 빌드 없이 즉시 참여합니다.

    등록한 URL과 같은 호스트/경로 범위만 크롤합니다 (sitemap 우선, robots.txt 존중, 페이지 수 제한). 등록하면 바로 첫 크롤과 빌드가 시작되고, 이후에는 주기적으로 재크롤해 내용이 바뀐 경우에만 다시 빌드합니다.

    선택한 공개 범위로 파일 소스를 등록합니다. 등록 후 브라우저에서 업로드하거나 안내된 S3 동기화 명령을 사용하세요. Markdown, 코드, PDF, DOCX, XLSX를 지원합니다. 텍스트가 적은 PDF의 본문 OCR을 사용하려면 “문서 AI 추출”과 “PDF 본문과 이미지 추출”을 모두 켜세요.
