    소스 등록

    퍼블릭 레포는 플랫폼 전체에서 공유(풀링)됩니다. 이미 등록된 레포라면 빌드 없이 즉시 참여합니다.

    등록한 URL과 같은 호스트/경로 범위만 크롤합니다 (sitemap 우선, robots.txt 존중, 페이지 수 제한). 등록하면 바로 첫 크롤과 빌드가 시작되고, 이후에는 주기적으로 재크롤해 내용이 바뀐 경우에만 다시 빌드합니다.

    내 계정 전용(프라이빗) S3 업로드 공간이 만들어집니다. 등록 후 안내되는 명령으로 폴더를 동기화하면 첫 빌드가 시작되고, 이후 변경도 자동으로 감지해 다시 빌드합니다. 마크다운 문서와 코드 파일을 지원합니다.

    업로드 위치 & 동기화 명령

    AWS CLI 자격 증명이 있는 터미널에서 실행하세요. 동기화가 끝나면 폴링 주기(기본 15분) 안에 빌드가 시작됩니다. API 키가 든 .mcp.json이나 .env 같은 시크릿 파일은 절대 동기화하지 마세요.

    공개 서버 카탈로그

    플랫폼에 등록된 모든 public 소스입니다. 구독하면 내 소스, MCP 서버 목록과 플레이그라운드에 나타나고, 내 API 키로 바로 쿼리할 수 있습니다. private 소스는 여기 나타나지 않으며, 소유자가 '멤버' 버튼으로 직접 공유해야 접근할 수 있습니다.

    서버 유형 소유자 빌드 상태 구독자 생성일 동작

    AI 추출 설정:

    저장하면 즉시 재빌드가 시작되고 문서(선택 시 이미지)가 Bedrock으로 전송됩니다. 변경된 문서만 다시 추출하며, 모델을 바꾸면 그 모델의 캐시를 새로 채우므로 첫 빌드는 전체 비용이 듭니다. 이미지 추출은 파일 소스에서만 켤 수 있습니다(크롤한 사이트는 이미지를 담지 않음).

    멤버 관리:

    사용자유형 추가일

    여기 추가된 사용자는 자신의 API 키로 이 서버에 접근하고 플레이그라운드에서 사용할 수 있습니다. private 소스를 특정 사용자에게만 공유하는 방법입니다. 허브(all) 병합 그래프에는 여전히 포함되지 않습니다. public 소스는 카탈로그에서 누구나 스스로 구독할 수 있습니다. 플랫폼에 없는 사용자는 관리자 탭에서 먼저 초대하세요.

    파일 관리:

    파일을 여기로 끌어다 놓으면 바로 업로드됩니다
