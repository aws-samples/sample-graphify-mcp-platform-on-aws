Graphify MCP Platform Setup

로컬 AWS 자격증명으로 graphify MCP 서버 스택을 배포·운영합니다. 이 콘솔은 127.0.0.1 전용입니다.

1환경 확인

2패키징 & 배포

패키징은 ARM64 휠 ~120MB를 받습니다(1–2분). 배포는 변경분만 반영되며 재실행해도 안전합니다.

3레포 등록

푸시 webhook은 레포 관리자만 설치할 수 있습니다(= 소유 검증). 등록 후 GitHub → Settings → Webhooks → Add webhook에 아래 값을 넣으세요. Content type은 application/json, 이벤트는 push만. webhook 유실 대비 6시간 안전 폴링이 함께 동작합니다.
